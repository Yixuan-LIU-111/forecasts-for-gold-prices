# 点时成金：黄金价格 30 分钟方向预测系统

## 需求规格说明书（SRS）

---

## 1\. 文档概述

### 1\.1 编写目的

本文档为「点时成金」AI 黄金价格预测系统的需求规格说明书，明确项目的功能需求、非功能需求、数据需求与验收标准，作为开发、测试与交付的依据。

### 1\.2 项目背景

黄金兼具商品、货币、避险资产、通胀对冲等多重属性，价格受美元指数、实际利率、地缘政治风险、央行购金行为、通胀预期等复杂因素影响。传统量化模型对突发事件反应滞后，且难以理解 "鹰派降息"、"避险情绪升温" 等复合语境。

本项目利用大语言模型（LLM）实时解析新闻、官员讲话、地缘事件，结合时序预测模型，输出未来 30 分钟黄金价格（XAU/USD）的上涨概率及预估幅度。

### 1\.3 项目目标

- **核心目标**：开发 AI 信号系统，实现 30 分钟级别黄金价格方向预测

- **方向准确率**：\> 60%

- **盈亏比**：\> 1\.5

- **夏普比率**：\> 1\.0（模拟交易）

- **信号延迟**：\< 3 秒

- **最大回撤**：\< 15%

### 1\.4 术语定义

|术语|定义|
|---|---|
|XAU/USD|黄金兑美元的交易代码，即国际金价|
|LLM|大语言模型，用于新闻情感分析与事件提取|
|GPR Index|地缘政治风险指数（Geopolitical Risk Index）|
|VIX|恐慌指数，CBOE 波动率指数|
|DXY|美元指数（US Dollar Index）|
|TIPS|通胀保值债券（Treasury Inflation\-Protected Securities）|
|NFP|非农就业人数变化（Non\-Farm Payrolls）|
|CPI|消费者物价指数（Consumer Price Index）|
|COT|持仓报告（Commitments of Traders）|
|AISC|全维持成本（All\-In Sustaining Cost）|
|鹰派|倾向于加息 / 紧缩货币政策|
|鸽派|倾向于降息 / 宽松货币政策|

### 3\.2 详细功能说明

#### F01 新闻数据采集

- **功能描述**：实时抓取与黄金价格相关的新闻、美联储官员讲话、经济数据公告、地缘政治事件

- **输入**：新闻 API 配置、关键词列表

- **处理逻辑**：

    1. 调用新闻 API 获取最新新闻

    2. 按关键词过滤与黄金相关的内容

    3. 去重、清洗、标准化

    4. 存入数据库，标记时间戳

- **输出**：结构化新闻数据（标题、内容、来源、时间、相关主题）

- **数据来源**：NewsAPI、GNews、美联储官网、白宫官网等

- **更新频率**：实时 / 每分钟

#### F02 市场数据采集

- **功能描述**：采集黄金及相关资产的实时市场数据

- **采集指标**：

    - XAU/USD 现货价格（分钟级）

    - 美元指数（DXY）

    - 美国 10 年期 TIPS 收益率

    - 美债 10Y\-2Y 利差

    - VIX 恐慌指数

    - WTI / Brent 原油价格

- **输出**：标准化时序数据

- **更新频率**：实时 / 每分钟

#### F04 新闻情感分析

- **功能描述**：使用 LLM 从新闻文本中提取对黄金价格的影响程度

- **输入**：新闻标题 \+ 正文

- **处理逻辑**：

    1. LLM 识别新闻主题（美联储、地缘冲突、通胀等）

    2. 判断事件动作（加息、降息、战争升级等）

    3. 评估对黄金的影响方向（利多 / 利空 / 中性）

    4. 输出情感强度分数（\-1 到 \+1）

    5. 判断超预期程度（实际值 vs 预期值的偏差）

- **输出**：

    - 黄金情感分数：\-1（强烈利空）\~ \+1（强烈利多）

    - 影响主题标签

    - 超预期程度

    - 置信度

#### F05 鹰鸽指数计算

- **功能描述**：从央行官员讲话中提取鹰派 / 鸽派程度，映射为黄金影响因子

- **映射规则**：

    - 鹰派（加息预期）→ 利空黄金（无息资产承压）

    - 鸽派（降息预期）→ 利多黄金

- **输出**：鹰鸽分数 → 黄金影响因子（\-0\.5 \~ \+0\.5）

#### F06 地缘风险量化

- **功能描述**：从新闻中提取地缘政治风险强度

- **处理逻辑**：

    1. 提取关键词："战争"、"袭击"、"制裁"、"冲突" 等

    2. 按事件严重程度加权

    3. 滑动窗口平滑处理

- **输出**：地缘风险分数（0 \~ 1）

- **备选方案**：接入 GPR 地缘政治风险指数

#### F07 时序预测模型

- **功能描述**：基于多因子输入，预测未来 30 分钟黄金价格涨跌

- **输入特征**：

    1. 价格序列特征：过去 30 分钟黄金价格收益率、波动率、买卖价差

    2. 情感特征：黄金情感分数（滚动窗口均值 / 极值）

    3. 政策特征：鹰鸽指数变化量

    4. 风险特征：地缘风险指数变化

    5. 市场特征：美元指数同期收益率、10 年期 TIPS 收益率变化

    6. 辅助特征：黄金期货持仓变化（低频）

- **模型选型**：

    - 基线模型：LightGBM / XGBoost

    - 进阶模型：LSTM / Transformer

- **输出**：

    - 未来 30 分钟上涨概率（0 \~ 1）

    - 预估收益率（例如 \+0\.15%）

    - 置信度

#### F08 信号生成器

- **功能描述**：聚合所有因子，生成最终交易信号

- **运行频率**：每 5 分钟

- **输出**：

    - 信号方向：看涨 / 看跌 / 观望

    - 信号强度：0 \~ 100

    - 建议仓位：轻仓 / 中仓 / 重仓

    - 止损止盈建议

#### F09 可视化仪表盘

- **功能描述**：Streamlit 实时展示系统运行状态

- **展示内容**：

    1. 实时黄金价格走势图

    2. 当前信号（方向、强度、概率）

    3. 最新新闻列表 \+ 情感标签

    4. 各因子实时数值（DXY、TIPS、VIX 等）

    5. 历史准确率统计

    6. 模拟交易收益曲线

#### F10 模拟交易接口

- **功能描述**：Backtrader 回测框架，验证信号有效性

- **功能点**：

    - 历史数据回测

    - 交易费用、滑点模拟

    - 绩效指标计算（收益率、夏普、最大回撤）

    - 交易明细导出

### 6\.3 宏观传导图谱（知识图谱）

存储黄金价格影响的因果链：

- 美债实际利率上升 → 黄金持有成本上升 → 黄金下跌

- 美元指数上涨 → 黄金下跌

- 通胀超预期 → 黄金上涨（抗通胀）

- 央行宣布增持黄金 → 黄金上涨

- 地缘冲突升级 → 避险情绪升温 → 黄金上涨
