# 黄金价格影响因素 - 数据爬虫智能体开发清单

## 文档说明

本文档根据《黄金价格影响因素细化表.xlsx》整理，用于指导数据爬虫智能体开发。清单覆盖**地缘政治、美国经济、佐证表象**三大类共 12 项指标，明确数据源、更新频率、获取方式、字段映射、调度策略及反爬/重试规范，确保后续 `feature_engineer.py` 可直接消费标准化数据。

---

## 一、执行约束（硬性规范）

| 约束项 | 规范 |
|--------|------|
| **HTTP 库** | 统一使用 `requests`；禁止切换 `httpx`、`urllib`、`selenium`、`playwright` 等多种工具反复测试。 |
| **重试机制** | 单页面请求最多重试 **2 次**（即首次 + 2 次重试 = 共 3 次请求）。超过 2 次仍失败，则停止并标注 **网站反爬限制**。 |
| **调试边界** | 代码生成完成即结束，不反复运行调试爬虫；异常与反爬限制以日志/字段形式记录，不在线反复重试。 |
| **数据对齐** | 所有指标最终写入统一时间戳（UTC+0 或北京时间）， minute 级数据需与 XAU/USD 分钟时间轴对齐。 |
| **时区与节假日** | 美国经济数据按美东时间发布；贵金属市场以 CME/London 交易时间为准；节假日缺失值按前向填充并标记 `ffill_flag`。 |

> **实时性等级说明**
> - `实时`：5–15 分钟刷新，用于 30 分钟在线推理。
> - `日频`：每日收盘后刷新，用于离线训练与低频特征。
> - `周度/月度/季度`：低频宏观因子，**仅用于离线训练**，不可用于实时推理。
> - `事件驱动`：数据发布后即时触发采集，需事件日历支撑。

## 四、爬虫代码规范

### 4.1 统一请求封装

```python
import requests
import time
import logging

logger = logging.getLogger(__name__)

MAX_RETRIES = 2
DEFAULT_TIMEOUT = 30


def fetch_page(url: str, headers: dict = None, timeout: int = DEFAULT_TIMEOUT) -> requests.Response:
    """
    统一页面请求封装。
    单页面最多重试 MAX_RETRIES 次，超过则停止并标注 anti_crawl。
    仅使用 requests，不切换其他 HTTP 工具。
    """
    headers = headers or {
        "User-Agent": "Mozilla/5.0 (compatible; GoldForecastBot/1.0)"
    }
    last_exception = None
    for attempt in range(MAX_RETRIES + 1):
        try:
            resp = requests.get(url, headers=headers, timeout=timeout)
            resp.raise_for_status()
            return resp
        except requests.RequestException as e:
            last_exception = e
            logger.warning(f"Request failed (attempt {attempt + 1}/{MAX_RETRIES + 1}): {url}, error={e}")
            if attempt < MAX_RETRIES:
                time.sleep(2 ** attempt)
    logger.error(f"Anti-crawl or unreachable site after {MAX_RETRIES} retries: {url}, error={last_exception}")
    raise AntiCrawlException(f"Failed to fetch {url} after {MAX_RETRIES} retries")


class AntiCrawlException(Exception):
    pass
```

### 4.2 数据记录标准字段

每条爬取记录必须包含以下字段，便于 `feature_engineer.py` 消费：

| 字段名 | 类型 | 说明 |
|--------|------|------|
| `indicator_code` | string | 指标唯一编码，如 `DXY`, `VIX` |
| `indicator_name` | string | 指标中文名称 |
| `category` | string | 分类：地缘政治 / 美国经济 / 佐证表象 |
| `timestamp` | datetime | 数据时间戳（UTC+0 或北京时间统一） |
| `value` | float | 指标数值 |
| `value_type` | string | 原始值 / 收益率 / 变化率 / 情感得分 |
| `source` | string | 实际来源，如 `FRED`, `CBOE`, `CFTC` |
| `source_url` | string | 来源网址 |
| `update_frequency` | string | 实时 / 日频 / 周度 / 月度 / 季度 |
| `realtime_inference` | bool | 是否可用于 30 分钟实时推理 |
| `ffill_flag` | bool | 是否为前向填充值 |
| `anti_crawl_flag` | bool | 是否因反爬/失败停止 |
| `raw_data` | json | 原始响应内容（用于调试与追溯） |
| `quality_score` | float | 数据质量评分 0–1 |
