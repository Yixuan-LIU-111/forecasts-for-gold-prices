## 第 7 章 技术栈选型

### 7.1 技术栈选型原则（Demo 阶段）
- 7.1.1 开发效率优先（快速验证核心假设）
- 7.1.2 团队熟悉度优先（降低学习成本）
- 7.1.3 可行性优先（成熟稳定、社区支持好）
- 7.1.4 渐进式升级（Demo 后可平滑过渡）

### 7.2 后端技术栈
- 7.2.1 编程语言：Python 3.10+
- 7.2.2 Web 框架：FastAPI（异步 + 自动 OpenAPI 文档）
- 7.2.3 数据校验：Pydantic v2
- 7.2.4 任务调度：APScheduler（单进程内调度，无需 Redis）
- 7.2.5 HTTP 客户端：httpx（异步 API 调用）

### 7.3 数据存储技术栈
- 7.3.1 关系数据库：PostgreSQL（Docker 镜像一键部署）
- 7.3.2 时序数据：PostgreSQL 分区表（Demo 数据量 < 100 万行）
- 7.3.3 ORM：SQLAlchemy 2.0
- 7.3.4 配置管理：pydantic-settings（环境变量）

### 7.4 机器学习技术栈
- 7.4.1 基线模型：LightGBM（快速训练、可解释性强）
- 7.4.2 对比模型：XGBoost（双模型 A/B 对比）
- 7.4.3 特征工程与评估：Scikit-learn
- 7.4.4 深度学习：暂不引入，架构预留 PyTorch 集成接口

### 7.5 LLM 调用技术栈
- 7.5.1 LLM 框架：LangChain（简化使用，仅用 ChatModel + PromptTemplate + OutputParser）
- 7.5.2 LLM 服务：OpenAI API（GPT-4o-mini 性价比最高）
- 7.5.3 不引入的组件：Agent、VectorStore、Memory（Demo 阶段过度设计）
- 7.5.4 成本控制：每日调用上限 + 新闻去重缓存

### 7.6 前端与可视化技术栈
- 7.6.1 仪表盘：Streamlit（纯 Python，零前端开发成本）
- 7.6.2 图表库：Plotly（Streamlit 内置，交互式图表）
- 7.6.3 数据处理展示：Pandas DataFrame 直接渲染

### 7.7 回测与量化技术栈
- 7.7.1 回测框架：Backtrader（支持滑点、手续费、多策略）
- 7.7.2 数据处理：Pandas + NumPy
- 7.7.3 市场数据源：yfinance（免费、分钟级数据）

### 7.8 部署技术栈
- 7.8.1 容器化：Docker + Docker Compose（2 容器：应用 + PostgreSQL）
- 7.8.2 依赖管理：Poetry 或 pip + requirements.txt
- 7.8.3 代码质量：black + ruff + pre-commit
- 7.8.4 测试：pytest

### 7.9 技术栈选型决策记录
- 7.9.1 方案三综合得分（47/60，加权 43.5/60）
- 7.9.2 与方案一（轻量）和方案二（工程化）的对比
- 7.9.3 选型决策依据

## 第 9 章 模型设计

### 9.1 模型体系总览

- 9.1.2 模型间数据流

- 9.2.1 输入设计（新闻标题 + 正文摘要）

- 9.2.3 输出设计（情感分数 -1~+1、主题标签、置信度）
- 9.2.4 黄金领域同义词库（QE=量化宽松=印钞，hawkish=鹰派=加息倾向）
- 9.2.5 输出解析（StrOutputParser + Pydantic 结构化）

### 9.3 鹰鸽指数模型
- 9.3.1 讲话文本识别（从新闻中筛选美联储官员讲话）
- 9.3.2 LLM 提取鹰派/鸽派程度
- 9.3.3 映射规则（鹰派 → -0.5，鸽派 → +0.5）
- 9.3.4 超预期程度计算（实际值 vs 市场预期）

### 9.4 时序预测模型
- 9.4.1 特征工程
  - 9.4.1.1 价格序列特征（30 分钟收益率、波动率、买卖价差）
  - 9.4.1.2 情感特征（滚动窗口均值/极值）
  - 9.4.1.3 政策特征（鹰鸽指数变化量）
  - 9.4.1.4 市场特征（DXY 收益率、TIPS 变化、VIX 水平）
- 9.4.2 基线模型：LightGBM
  - 9.4.2.1 超参数设置（num_leaves、learning_rate、n_estimators）
  - 9.4.2.2 早停策略（early_stopping_rounds）
  - 9.4.2.3 特征重要性分析
- 9.4.3 对比模型：XGBoost
  - 9.4.3.1 超参数设置
  - 9.4.3.2 与 LightGBM 对比维度
- 9.4.4 双模型集成策略（加权平均 / 投票）
- 9.4.5 输出设计（上涨概率 0~1、预估收益率、置信度）

### 9.5 模型训练与评估
- 9.5.1 数据集划分（训练 70% / 验证 15% / 测试 15%）
- 9.5.2 Walk-Forward 验证方法（防止特征泄露）
- 9.5.3 评估指标（准确率、F1、AUC、对数损失）
- 9.5.4 过拟合检测（训练集与测试集差异 >15% 告警）
