| 缺陷 | 严重度 | 状态 | 关联用例 | 说明 |
|------|--------|------|----------|------|
| DEF-001 回测「取最新」排序不确定（SQLite 秒级同值） | 高 | **已修复** | IT-BIZ-02 | 追加 `desc(BacktestResult.id)` 次级排序键 |
| DEF-002 框架级 422 未包统一信封 | 中 | 跟踪（xfail） | AP-16 | 待加异常中间件 |
| DEF-003 非法 start_date 被静默忽略 | 中 | 跟踪（xfail） | AP-17 | 待加日期校验 |
| DEF-004 demo 无鉴权 | 高（上线前） | 跟踪（xfail） | SEC-10 | 上线前必须补 API Key/JWT |
| DEF-005 CORS `*` 全开 | 中（上线前） | 跟踪（xfail） | SEC-11 | 上线前收敛白名单 |
| DEF-006 缺安全响应头 | 中（上线前） | 跟踪（xfail） | SEC-12 | 补 CSP/HSTS/X-Frame-Options |

> 约定：xfail 用例代表「已知且已记录」的缺陷，不计入失败；一旦修复，对应 xfail 将转为 xpass 并由 `--strict-markers` 提醒移除标记。
