## 二、数据流架构

### 2.1 前后端接口契约

前端统一通过 **FastAPI** 接口获取数据，不直接读 PostgreSQL。

| 编号 | 接口 | 方法 | 路径 | 响应 | 缓存 | 刷新机制 |
|------|------|------|------|------|------|---------|
| API-01 | 最新信号 | GET | `/api/v1/signal/latest` | 信号对象 | 无 | **SSE 推送** / 5秒轮询 |
| API-02 | 行情数据 | GET | `/api/v1/market/xauusd?range=1d` | 价格数组 | 60s | 60秒轮询 |
| API-03 | 多因子数据 | GET | `/api/v1/factors/latest` | 因子列表 | 30s | 30秒轮询 |
| API-04 | 鹰鸽指数 | GET | `/api/v1/factors/hawk-dove?days=7` | 事件数组 | 5min | 5分钟轮询 |
| API-05 | 新闻列表 | GET | `/api/v1/news?limit=20&offset=0` | 新闻数组 | 30s | 30秒轮询 |
| API-06 | 运行回测 | POST | `/api/v1/backtest/run` | 回测结果对象 | 无 | 按需触发 |
| API-07 | 回测结果 | GET | `/api/v1/backtest/latest` | 回测结果对象 | 5min | 5分钟轮询 |
| API-08 | 准确率统计 | GET | `/api/v1/accuracy?window=7d` | 统计对象 | 5min | 5分钟轮询 |
| API-09 | 系统状态 | GET | `/api/v1/system/status` | 状态对象 | 10s | 10秒轮询 |
| API-10 | 因子归因 | GET | `/api/v1/signal/attribution` | 归因列表 | 无 | 随信号刷新 |

### 2.2 实时性分级

| 数据类别 | 刷新方式 | 频率 | 延迟要求 | 理由 |
|---------|---------|------|---------|------|
| **信号** | SSE / 5秒轮询 | 5秒 | < 3秒 | 核心决策数据，用户感知最强 |
| **行情价格** | 短轮询 | 60秒 | < 60秒 | 价格走势不需要毫秒级 |
| **多因子** | 短轮询 | 30秒 | < 30秒 | 非极端行情变化缓慢 |
| **新闻列表** | 短轮询 | 30秒 | < 30秒 | 新闻发布频率低 |
| **回测/统计** | 按需 | — | < 5秒 | 用户主动触发 |

### 2.3 前端数据流图

```
Streamlit Dashboard
    │
    ├── SSE Client (信号) ──────→ API-01 → 信号面板 + 归因图
    │
    ├── Timer Manager (60s) ───────→ API-02 → 行情走势图
    ├── Timer Manager (30s) ───────→ API-03 → 因子卡片
    ├── Timer Manager (5min) ──────→ API-04 → 鹰鸽时间线
    ├── Timer Manager (30s) ───────→ API-05 → 新闻列表
    ├── User Action (点击) ────────→ API-06 → 回测结果
    ├── Timer Manager (5min) ──────→ API-08 → 准确率统计
    └── Timer Manager (10s) ───────→ API-09 → 状态栏
```

## 三、核心组件详细设计

### 3.1 顶部状态栏

| 元素 | 实现 | 说明 |
|------|------|------|
| 系统运行状态 | 圆点指示灯 🟢/🟡/🔴 | 绿=正常，黄=降级，红=异常 |
| SSE 连接状态 | 独立指示灯 + "信号实时"标签 | 断开时闪烁警告 |
| 当前时间 | `datetime.now().strftime()` | 每秒更新 |
| 数据刷新倒计时 | 显示"下次刷新: 45s" | 配合各定时器 |
| 演示模式开关 | `st.toggle("演示模式")` | 开启后使用预录制数据 |

### 3.2 信号面板（核心决策区）

**布局**：`st.columns(5)` 水平排列

#### 3.2.1 方向信号卡片

```
┌──────────────────────┐
│      📈 信号方向       │
│                      │
│   ● 看涨 (BULLISH)    │  ← 绿色 #00C853
│                      │
│   置信度: 高          │
└──────────────────────┘
```

- 看涨 → 绿色 `#00C853` | 看跌 → 红色 `#FF1744` | 观望 → 灰色 `#9E9E9E`
- 使用 `st.container` + 自定义 CSS 圆角边框 + 阴影
- 背景色渐变填充，颜色对应信号方向

#### 3.2.2 上涨概率（半圆仪表盘）

```
         ╔══ 62% ══╗
      ╔══╝         ╚══╗
     ╔══    ██████    ══╗
     ║  0% ──────→ 100% ║
     ╚══               ══╝
      ╚══╗         ╔══╝
         ╚══ 0.62 ══╝
```

- 使用 Plotly Gauge Chart
- 颜色渐变：<40% 红 → 40-60% 黄 → >60% 绿
- 中心显示百分比数字，下方显示小数

#### 3.2.3 信号强度（进度条）

```
信号强度: 72/100
████████████████░░░░░░░░░
[强] ← 颜色: >60 绿, 30-60 蓝, <30 灰
```

- 使用 `st.progress()` 或自定义 HTML
- 强度标签：0-30 弱 | 30-60 中 | 60-100 强

#### 3.2.4 建议仓位

```
┌──────────────────┐
│  建议仓位         │
│                  │
│   ● 中仓 (50%)   │  ← 颜色对应强度
│                  │
│  风控限制: 正常   │
└──────────────────┘
```

- 轻仓(25%) 淡蓝 | 中仓(50%) 蓝 | 重仓(75%) 深蓝
- 仓位映射规则：概率 < 0.55 → 观望(0%)，0.55-0.65 → 轻仓，0.65-0.75 → 中仓，> 0.75 → 重仓

#### 3.2.5 多空评分条

```
多空评分: 62/100 (偏多)
← 看空 ────────────●─────────── 看多 →
  0               50          100
```

- 使用 Plotly 水平条形图或自定义 HTML
- 滑块位置指示当前评分
- 颜色渐变：左红 → 中灰 → 右绿

#### 3.2.6 因子贡献度归因条形图

```

─────────────────────────────────────────────────
新闻情感     +0.35  ████████████████████     ⭐ 点击
鹰鸽指数     +0.20  ██████████                 ⭐ 点击
```

### 3.3 实时行情走势图

| 属性 | 设计 |
|------|------|
| 图表类型 | Plotly 交互式折线图 |
| 数据 | XAU/USD 价格时间序列 |

### 3.4 多因子实时卡片 + 鹰鸽指数

**布局**：右栏 35% 宽度，分为上下两部分

#### 3.4.1 因子卡片（上）

使用 `st.columns(2)` 排列，每因子一张卡片：

| 因子 | 数据源 | 格式 | 趋势指示器 | 最近值示例 |
|------|--------|------|-----------|-----------|
| DXY | API-03 | 三位小数 | ↑红/↓绿/→灰 | 101.5536 ↑ |
| TIPS | API-03 | 两位小数+% | ↑红/↓绿/→灰 | 2.44% ↓ |
| VIX | API-03 | 两位小数 | ↑红/↓绿/→灰 | 15.32 → |
| GPR | API-03 | 三位小数 | ↑红/↓绿/→灰 | 195.90 ↑ |
| 情感分数 | API-03 | -1~+1 两位小数 | 绿/红/灰 | +0.32 ↑ |
| 鹰鸽指数 | API-03 | -0.5~+0.5 | 绿/红/灰 | -0.15 ↓ |

每个卡片使用 `st.metric()` 展示，趋势箭头颜色逻辑：
- DXY 上涨 → 红色（利空黄金），DXY 下跌 → 绿色（利好黄金）
- TIPS 上涨 → 红色（利空黄金），TIPS 下跌 → 绿色（利好黄金）
- VIX 上涨 → 绿色（利好黄金，避险情绪），VIX 下跌 → 红色
- 情感分数 > 0 → 绿色，< 0 → 红色

## 四、异常状态处理矩阵

| 场景 | 信号面板 | 行情图 | 因子卡片 | 新闻列表 | 回测 |
|------|---------|--------|---------|---------|------|
| **数据加载中** | 灰色骨架屏 + `st.spinner` | 灰色占位图 | 灰色占位卡片 | 骨架屏列表 | 禁用按钮 + 加载动画 |

## 五、演示模式设计

### 5.1 触发方式
- 侧边栏 `st.toggle("🎬 演示模式")` 或 URL 参数 `?demo=true`
- 状态存储在 `st.session_state.demo_mode`

### 5.2 数据策略
- 预录制 3 天历史数据，存储在 `app/dashboard/demo_data/` 目录下
- 每个 API 对应一个 JSON 文件：
  - `demo_data/signals.json` — 模拟信号变化
  - `demo_data/market.json` — 模拟行情演变
  - `demo_data/news.json` — 模拟新闻流

### 5.3 演示场景
- 自动播放：信号从看跌 → 观望 → 看涨的自然演变过程

- 演示场景包括：
  1. 正常市场（随机波动）
  2. 重大利多事件（美联储降息信号）
  3. 重大利空事件（地缘冲突升级）
  4. 数据源不可用（降级模式演示）

## 九、设计原则

1. **信息层级清晰**：核心决策信息（信号）在最上方，操作信息（回测）居中，参考信息（新闻、状态）在下
2. **颜色即语义**：绿色=看涨/利好，红色=看跌/利空，灰色=中性/观望，避免用户额外认知负担
3. **可解释性优先**：每条信号附带因子归因，每条新闻附带情感分析明细，不黑盒
4. **优雅降级**：任一数据源不可用时，系统不崩溃，而是降级运行并明确告知用户
5. **演示即真实**：演示模式使用真实数据的子集，确保演示体验与真实一致
