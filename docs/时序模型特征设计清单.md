# 黄金价格影响因素 - 时序模型特征设计清单

## 文档说明

本文档根据《黄金价格影响因素细化表.xlsx》整理，用于指导 30 分钟 XAU/USD 方向预测时序模型的特征设计。清单完整覆盖 12 项影响指标的量化方案、传导逻辑、与金价的数学关系、特征变换、滞后窗口及实时推理可用性，确保特征工程与爬虫采集清单严格对齐。

---

## 二、详细特征设计

### 2.1 地缘政治类

#### 2.1.1 地缘政治风险指数 (`GPR`)

| 项目 | 内容 |
|------|------|
| **特征编码** | `GPR` |
| **指标名称** | 地缘政治风险指数 |
| **量化方案** | Caldara and Iacoviello GPR 指数；或新闻中战争/冲突关键词频率计数 |
| **传导逻辑** | 地缘冲突引发市场恐慌和不确定性，投资者寻求避险资产，推动资金流入黄金 |
| **与金价关系** | 正相关；事件初期显著正向冲击，系数随事件持续时间衰减，具有非线性特征 |
| **特征类型** | 数值型 |
| **特征变换** | 原始值、对数变化率、滚动均值（7/30 日）、历史分位数、事件突破标记 |
| **建议滞后/窗口** | 1–3 日；突破历史 95% 分位数标记地缘事件 |
| **实时推理** | 月度官方 GPR 不可用；在线推理使用新闻关键词实时计数替代 |
| **更新频率** | 每月（官方 GPR）/ 实时（新闻） |
| **交互特征** | `GPR × VIX`（地缘冲突叠加恐慌）、`GPR × 黄金波动率` |

#### 2.1.2 VIX 恐慌指数 (`VIX`)

| 项目 | 内容 |
|------|------|
| **特征编码** | `VIX` |
| **指标名称** | VIX 恐慌指数 |
| **量化方案** | CBOE 波动率指数点位 / 对数变化率 |
| **传导逻辑** | 股市波动率上升反映市场恐慌，资金从风险资产撤出，转向黄金等避险资产 |
| **与金价关系** | 正相关；危机时期相关性显著增强 |
| **特征类型** | 数值型 |
| **特征变换** | 原始值、对数收益率、VIX 期限结构斜率、高波动标记（>30） |
| **建议滞后/窗口** | 1–5 分钟（高频）、1–2 日（低频） |
| **实时推理** | ✅ 实时可用 |
| **更新频率** | 实时/每日 |
| **交互特征** | `VIX × DXY`（恐慌与美元走强对冲）、`VIX × 黄金收益率` |

#### 2.1.3 原油期货价格 (`OIL_WTI` / `OIL_BRENT`)

| 项目 | 内容 |
|------|------|
| **特征编码** | `OIL_WTI`, `OIL_BRENT` |
| **指标名称** | WTI / Brent 原油期货价格 |
| **量化方案** | 美元/桶价格 / 对数收益率 |
| **传导逻辑** | 油价上涨推高生产和运输成本，引发通胀预期，间接支撑金价；产油国收入增加可能提升黄金储备需求 |
| **与金价关系** | 间接正相关；通过通胀预期传导，直接回归系数可能不显著 |
| **特征类型** | 数值型 |
| **特征变换** | 原始价格、对数收益率、滚动波动率、 Brent-WTI 价差 |
| **建议滞后/窗口** | 1–2 日 |
| **实时推理** | ✅ 实时/日频可用 |
| **更新频率** | 实时/每日 |
| **交互特征** | `原油价格 × CPI 意外值`、`原油价格 × DXY` |

#### 2.1.4 美元指数 (`DXY`)

| 项目 | 内容 |
|------|------|
| **特征编码** | `DXY` |
| **指标名称** | 美元指数 |
| **量化方案** | ICE 美元指数点位 / 对数收益率 `R_dxy = ln(P_t/P_t-1)` |
| **传导逻辑** | 美元升值增加非美货币持有者购买黄金成本，抑制需求；美元走强吸引资金流出黄金 |
| **与金价关系** | 负相关；弹性系数通常在 -0.5 到 -1.0 之间 |
| **特征类型** | 数值型 |
| **特征变换** | 原始值、对数收益率、滚动标准差、趋势方向标记 |
| **建议滞后/窗口** | 1–5 分钟（高频）、1 日（低频） |
| **实时推理** | ✅ 日频前向填充 + 盘中 extrapolate |
| **更新频率** | 实时/每日 |
| **交互特征** | `DXY × 原油价格`、`DXY × 实际利率`、`DXY × 季节性虚拟变量` |

### 2.2 美国经济类

#### 2.2.1 主席/总统讲话情感得分 (`SPEECH_SENT`)

| 项目 | 内容 |
|------|------|
| **特征编码** | `SPEECH_SENT` |
| **指标名称** | 美联储主席/美国总统讲话情感得分 |
| **量化方案** | FinBERT/BERT 对讲话文本输出 `[-1, 1]` 情感得分；鹰派负分、鸽派正分 |
| **传导逻辑** | 鹰派讲话倾向加息/紧缩利空黄金；鸽派讲话倾向降息/宽松利好黄金；市场即时反应剧烈 |
| **与金价关系** | 负相关（鹰派得分）/ 正相关（鸽派得分）；30 分钟内收益率呈显著线性或非线性关系 |
| **特征类型** | 数值型 |
| **特征变换** | 原始情感得分、得分变化量、情绪极性标记、鹰鸽指数 |
| **建议滞后/窗口** | 事件驱动：发布后 1–60 分钟；事件窗口：发布前 30 分钟至发布后 2 小时 |
| **实时推理** | ✅ 事件窗口可用 |
| **更新频率** | 不定期（事件驱动） |
| **交互特征** | `SpeechSent × VIX`、`SpeechSent × DXY` |

#### 2.2.2 非农就业 / 失业率 / GDP (`NFP` / `UNEMP` / `GDP`)

| 项目 | 内容 |
|------|------|
| **特征编码** | `NFP`, `UNEMP`, `GDP` |
| **指标名称** | 非农就业人数变化 / 失业率 / GDP 增长率 |
| **量化方案** | 实际值与预测值偏差（Surprise Index）/ 环比或同比增长率 |
| **传导逻辑** | 强劲经济数据强化加息预期和美元走强，利空黄金；反之利好黄金 |
| **与金价关系** | 负相关（数据超预期时）；数据意外值与金价短期变动呈负相关 |
| **特征类型** | 数值型 |
| **特征变换** | 意外值、标准化意外值、方向标记（超预期/不及预期）、事件虚拟变量 |
| **建议滞后/窗口** | 事件窗口：发布前 1 分钟至发布后 30 分钟 |
| **实时推理** | ❌ 月度/季度低频，仅离线训练使用 |
| **更新频率** | 月度（NFP、失业率）/ 季度（GDP） |
| **交互特征** | `NFP 意外值 × DXY`、`NFP 意外值 × FED_RATE` |

#### 2.2.3 CPI / PCE 通胀 (`CPI` / `PCE`)

| 项目 | 内容 |
|------|------|
| **特征编码** | `CPI`, `PCE` |
| **指标名称** | 美国 CPI 同比/环比 / PCE 物价指数 |
| **量化方案** | 同比百分比变化 `ΔCPI_yoy` / 意外值（实际值 - 预测值） |
| **传导逻辑** | 通胀侵蚀法币购买力，黄金作为保值工具需求增加；预期外通胀影响更大 |
| **与金价关系** | 正相关；高利率环境下若加息遏制通胀，可能出现短期负向反应 |
| **特征类型** | 数值型 |
| **特征变换** | 同比变化率、环比变化率、意外值、核心 CPI、事件虚拟变量 |
| **建议滞后/窗口** | 1–2 月 |
| **实时推理** | ❌ 月度低频，仅离线训练使用 |
| **更新频率** | 每月 |
| **交互特征** | `CPI 意外值 × 实际利率`、`CPI 意外值 × DXY` |

#### 2.2.4 货币政策 (`FED_RATE` / `FED_BS`)

| 项目 | 内容 |
|------|------|
| **特征编码** | `FED_RATE`, `FED_BS` |
| **指标名称** | 联邦基金目标利率 / 美联储资产负债表规模 |
| **量化方案** | 利率点位（%）/ 资产负债表总额（万亿美元）/ QE/QT 虚拟变量 |
| **传导逻辑** | 降息或扩表增加流动性、压低利率，利好黄金；加息或缩表收紧流动性，利空黄金 |
| **与金价关系** | 利率负相关 / 资产负债表正相关；利率变动呈阶梯式冲击 |
| **特征类型** | 数值型 / 虚拟变量 |
| **特征变换** | 利率水平、利率变化量、资产负债表同比增长率、QE/QT 虚拟变量 |
| **建议滞后/窗口** | 利率：事件窗口（FOMC 前后 1 小时）；资产负债表：1–4 周 |
| **实时推理** | FED_RATE：事件窗口可用；FED_BS：日频可用 |
| **更新频率** | 利率：不定期（FOMC）/ 资产负债表：每周 |
| **交互特征** | `FED_RATE × CPI 意外值`、`FED_BS × 实际利率` |

#### 2.2.5 实际利率 (`TIPS10Y`)

| 项目 | 内容 |
|------|------|
| **特征编码** | `TIPS10Y` |
| **指标名称** | 美国 10 年期通胀保值债券收益率 (TIPS) |
| **量化方案** | 直接使用 TIPS 收益率作为实际利率代理变量 |
| **传导逻辑** | 黄金是无息资产，实际利率代表持有黄金的机会成本；实际利率上升，持有成本增加，金价下跌 |
| **与金价关系** | 强负相关；通常被认为是金价最核心的驱动因子 |
| **特征类型** | 数值型 |
| **特征变换** | 原始收益率、收益率变化量、与名义利率差值、滚动均值 |
| **建议滞后/窗口** | 1–2 日 |
| **实时推理** | ✅ 日频前向填充 |
| **更新频率** | 每日 |
| **重要性标记** | ⭐⭐⭐ 核心驱动因子 |
| **交互特征** | `TIPS × DXY`、`TIPS × CPI 意外值` |

#### 2.2.6 美债收益率利差 (`T10Y2Y`)

| 项目 | 内容 |
|------|------|
| **特征编码** | `T10Y2Y` |
| **指标名称** | 美债 10Y-2Y 收益率利差 |
| **量化方案** | 10Y 收益率 - 2Y 收益率（bps） |
| **传导逻辑** | 利差倒挂预示经济衰退风险，提升避险需求利好黄金；利差走阔伴随经济过热或加息预期，利空黄金 |
| **与金价关系** | 非线性/负相关；倒挂程度加深（数值变小或为负）通常利好黄金 |
| **特征类型** | 数值型 |
| **特征变换** | 原始利差、利差变化量、倒挂虚拟变量（<0）、深度倒挂标记（<-25 bps） |
| **建议滞后/窗口** | 1–2 日 |
| **实时推理** | ✅ 日频前向填充 |
| **更新频率** | 实时/每日 |
| **交互特征** | `CurveInversion × VIX`、`CurveInversion × TIPS` |

### 2.3 佐证表象类

| **与金价关系** | 正相关；短期正相关，极端值时可能出现反向指标效应 |
| **特征类型** | 数值型 |
| **特征变换** | 净持仓量、净持仓占比、持仓变化率、极值标记（>90% 分位数） |

| **更新频率** | 每周（周五发布） |
| **交互特征** | `CFTC_NET × 金价波动率`、`CFTC_NET × ETF 持仓变化` |

#### 2.3.2 黄金 ETF 持仓 (`ETF_GLD` / `ETF_TOTAL`)

| 项目 | 内容 |

| **指标名称** | 全球主要黄金 ETF 持仓总量 |
| **量化方案** | SPDR Gold Shares (GLD) 等主流 ETF 每日持仓变动量 |
| **传导逻辑** | ETF 持仓直接代表投资性需求；持仓增加意味着真金白银买入，支撑金价；反之构成抛压 |
| **与金价关系** | 强正相关；持仓量变动与金价变动高度同步 |
| **特征类型** | 数值型 |
| **特征变换** | 持仓总量、持仓变化量、持仓同比增长率、滚动均值 |
| **建议滞后/窗口** | 1–2 日 |
| **实时推理** | ✅ 日频前向填充 |
| **更新频率** | 每日 |
| **重要性标记** | ⭐⭐ 需求面重要指标 |
| **交互特征** | `ETF 持仓变化 × 金价动量`、`ETF 持仓变化 × DXY` |

## 三、特征工程建议

### 3.1 时间序列特征

| 特征类型 | 生成方法 | 适用指标 |
|----------|----------|----------|
| 滞后特征 | `t-1`, `t-2`, `t-5`, `t-10`, `t-30` | 所有数值型指标 |
| 滚动统计 | 7 日/30 日滚动均值、标准差、偏度 | VIX、DXY、原油价格、ETF 持仓 |
| 差分特征 | 一阶差分、对数差分 | 价格类指标 |
| 移动平均 | SMA(5,20,60), EMA(12,26) | 价格类指标 |
| 波动率 | Garman-Klass 波动率、ATR | VIX、原油、黄金价格 |
| 价格动量 | 5 分钟/10 分钟/30 分钟收益率 | XAU/USD 价格 |
| 价格区间 | 30 分钟滚动最高价-最低价价差 | XAU/USD 价格 |

### 3.2 事件特征

| 特征类型 | 生成方法 | 适用场景 |
|----------|----------|----------|
| 事件标记 | 发布日标记为 1，其余为 0 | 非农、CPI、FOMC 会议 |
| 事件窗口 | 发布前后一段时间窗口 | 数据发布、讲话事件 |
| 意外值 | 实际值 - 市场预期值 | 经济数据发布 |
| 情绪得分 | NLP 情感分析结果 | 讲话、新闻 |

### 3.3 非线性/交互特征

| 特征类型 | 生成方法 | 适用场景 |
|----------|----------|----------|
| 平方项 | `x²` | 检验非线性关系 |
| 交互项 | `x1 × x2` | 利率×通胀、美元×原油、VIX×DXY |
| 阈值分割 | 根据分位数或经济意义划分区间 | VIX 高/低波动期、利差倒挂 |
| 对数变换 | `ln(x)` 或 `ln(1+x)` | 价格类指标 |
| 标准化 | z-score 标准化 | 跨指标比较（情感因子保留 `[-1,1]` 不变） |

## 四、特征选择优先级

### 4.1 核心特征（强烈推荐）

| 优先级 | 指标编码 | 指标 | 理由 |
|--------|----------|------|------|
| 1 | `TIPS10Y` | 实际利率 (TIPS) | 金价最核心驱动因子，相关性极高 |
| 2 | `DXY` | 美元指数 | 直接影响黄金计价和需求 |
| 3 | `VIX` | VIX 指数 | 反映即时市场风险偏好 |
| 4 | `ETF_GLD` | ETF 持仓 | 代表真实投资需求 |

### 4.2 重要特征（建议包含）

| 优先级 | 指标编码 | 指标 | 理由 |
|--------|----------|------|------|
| 5 | `T10Y2Y` | 收益率利差 | 预测经济周期转折点 |
| 6 | `SPEECH_SENT` | 讲话情感得分 | 短期市场情绪冲击 |
| 7 | `NFP` / `CPI` | 非农/CPI 意外值 | 重大经济数据影响 |
| 8 | `FED_RATE` / `FED_BS` | 货币政策变量 | 中长期趋势驱动 |

### 4.3 辅助特征（视情况添加）

## 六、数据标准化与泄漏防护

### 6.1 标准化规则

| 特征类型 | 处理方式 |
|----------|----------|
| 时间序列价格/收益率 | z-score 标准化，按训练集统计量计算 |
| 情感得分 | 保留 `[-1, 1]` 原始范围，不做缩放 |
| 鹰鸽指数 | 保留 `[-0.5, 0.5]` 原始范围，不做缩放 |
| 地缘风险分数 | 保留 `[0, 1]` 原始范围，不做缩放 |

### 6.2 数据泄漏防护

| 项目 | 规范 |
|------|------|
| 时间排序 | 所有 Train/Validation/Test 按时间顺序划分，禁止随机打乱 |
| 滚动窗口 | 滚动统计量仅使用当前时刻及之前的数据，禁止引入未来信息 |
| 标准化 | z-score 参数在训练集上计算，验证/测试集复用训练集参数 |
| 滞后特征 | 所有滞后特征严格使用 `t-k` 时刻数据 |
| 事件特征 | 事件虚拟变量以实际发布时间为触发点，禁止事后标记 |
