## 1. 项目概览

本项目是一个面向 XAUUSD（现货黄金/美元）的 30 分钟预测系统，核心目标是为交易者提供方向性信号（涨/跌）及可解释归因。项目采用 **Python 全栈** 方案，前端为 Streamlit 仪表盘 + 静态 HTML 原型，后端为 FastAPI + SQLAlchemy/SQLite，业务逻辑集中在 `app/core/`，数据采集由 9 个独立爬虫包负责。

当前运行模式默认为 **DEMO_MODE=True**：使用 `app/core/seed.py` 注入的演示种子数据启动，可在 `.env` 中切换为实时模式。

## 3. 分层架构

项目整体按经典 **表现层 → 接口层 → 业务逻辑层 → 数据访问层 → 数据采集层** 组织：

### 3.1 表现层（Presentation）

- **`app/dashboard/app.py`**：Streamlit 仪表盘，侧边栏导航 4 个页签：
  1. 仪表盘概览
  2. 实时行情
  3. 回测分析
  4. 新闻动态
- **`frontend/dashboard.html`**：静态原型，使用 Plotly + oklch 配色，已对齐“涨红跌绿”。
- **同源托管**：`app/main.py` 将 `/`、`/dashboard`、`/dashboard.html` 映射到该 HTML 文件。

### 3.2 接口层（FastAPI）

已合并入主项目，不再是截图所示的“缺失”状态。路由模块：

## 5. 数据流向

1. **采集**：`news_scraper_llm` 等爬虫产出原始数据。
2. **落地**：
   - 文件轨道：`data/*.json`、`data/*.jsonl`、`data/*.csv`（latest 快照 + history 追加）。
   - 数据库：`data/gold_predictor.db`（10 张表）。
3. **决策**：
   - 主链路：`core/signal_generator.py` 读取最新因子，执行 **6 因子人工加权规则** 生成方向/置信度/归因。
   - 旁路：`gold_prediction_model/` 离线训练 LightGBM+XGBoost，输出到 `reports/*.html`，**结果不回流**。
4. **展示**：Streamlit 仪表盘或 `frontend/dashboard.html` 展示信号、行情、回测、新闻。

> 当前核心缺口：`gold_prediction_model` 训练管线与 `app/core` 主链路未打通；多数因子爬虫与数据库未打通。

## 7. 关键架构模式与设计决策

### 7.1 分层与依赖方向

严格遵循 **上层依赖下层、下层不依赖上层**：
- `app/api/` → `app/core/` / `app/models/`
- `app/core/` → `app/models/`
- `*_scraper/` → `data/` 或 `app/models/`
- `gold_prediction_model/` 独立，不反向依赖 `app/`

### 7.2 配置中心化

`app/config.py` 通过 `pydantic-settings` 统一读取 `.env`，并保留大写字段别名（如 `DATABASE_URL`）兼容旧代码，避免合并两套代码时大规模重构。

### 7.3 DEMO / LIVE 双模式

- `DEMO_MODE=True`：启动时注入种子数据，保证无外部 API 也能演示。
- `SCHEDULER_ENABLED=True`：即使 DEMO 模式，也允许新闻爬虫任务运行，展示真实动态数据。
- `DEMO_MODE=False`：切换为实时采集/信号生成。

### 7.4 统一配色约束

“涨红跌绿”是硬约束：
- `app/dashboard/config.py`：红 `#ef5350`，绿 `#26a69a`。
- `frontend/dashboard.html`：oklch 色空间实现相同语义。

### 7.5 30 分钟预测窗口

固定预测 horizon 为 30 分钟；`gold_prediction_model/thirty_min/config.py` 中保留 `HORIZON_MINUTES` 等命名，但 `app/config.py` 尚未统一该命名。
