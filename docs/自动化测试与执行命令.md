# 「点时成金」自动化测试与执行命令

> 本文给出「开箱即跑」的完整命令清单。所有脚本与文档均为中文注释。
> 实测结论：默认（离线）一键执行即可跑完 **261 passed / 6 xfailed / 0 failed**，并生成 HTML 测试报告 + 覆盖率报告。

---

## 1. 测试资产一览

| 资产 | 路径 | 作用 |
|------|------|------|
| 一键脚本 | `scripts/run_tests.sh` | 12 种模式，自动装依赖、生成报告 |
| 测试配置 | `pytest.ini` | 发现规则、标记、超时、严格标记 |
| 覆盖率配置 | `.coveragerc` | 统计范围、分支覆盖率、忽略项 |
| 测试依赖 | `requirements-test.txt` | 仅测试工具链（不含 lightgbm/streamlit/playwright） |
| 隔离配置 | `tests/conftest.py` | 注入测试环境变量、提供 `client`/`db`/`api` fixture |
| 用例 | `tests/*.py` | 8 个文件，详见《测试用例设计》 |

---

## 2. 一键执行（推荐）

```bash
# 在项目根目录（forecasts for gold prices/）执行
bash scripts/run_tests.sh
```

脚本会自动：
1. 选择解释器：优先 `.venv/bin/python`，否则回退 `python3`；
2. 检查并安装测试依赖（缺失才装，幂等）；
3. 以 `not external` 跑全量（单元 / 接口 / 集成 / 端到端 / 性能 / 安全，排除需外网的 `external`）；
4. 生成 `reports/` 下全部产物；
5. 打印并写入 `reports/summary.txt` 执行摘要。

---

## 3. 分模式执行

| 命令 | 范围 | 典型用途 |
|------|------|----------|
| `bash scripts/run_tests.sh smoke` | 单元 + 接口 | 提交前秒级冒烟 |
| `bash scripts/run_tests.sh unit` | 仅单元测试 | 算法回归 |
| `bash scripts/run_tests.sh api` | 仅接口测试 | 契约 / 边界回归 |
| `bash scripts/run_tests.sh integration` | 仅集成测试 | 数据 / 回测一致性 |
| `bash scripts/run_tests.sh e2e` | 端到端前端 | 前端 / 接口对齐 |
| `bash scripts/run_tests.sh perf` | 仅性能基线 | SLA 守门 |
| `bash scripts/run_tests.sh security` | 仅安全基线 | 安全红线 / 门禁 |
| `bash scripts/run_tests.sh full` | 含 `external` 全量 | 需外网 / Node，含 jsdom |
| `bash scripts/run_tests.sh install` | 仅装依赖 | CI 预装阶段 |

## 4. 手动执行（等价于脚本内部行为）

```bash
# ① 安装测试依赖（仅首次 / 依赖变更时）
.venv/bin/python -m pip install -q -r requirements-test.txt

# ② 全量回归（带覆盖率 + 报告）
.venv/bin/python -m pytest tests \
  -v --color=yes --timeout=120 \
  --junitxml=reports/junit.xml \
  --html=reports/pytest-report.html --self-contained-html \
  --cov=app --cov-report=term-missing:skip-covered \
  --cov-report=html:reports/coverage-html \
  --cov-report=xml:reports/coverage.xml \
  --cov-config=.coveragerc \
  -m "not external"

# ③ 仅跑某一标记
.venv/bin/python -m pytest tests -m "security" -v
.venv/bin/python -m pytest tests -m "perf" -v

# ④ 并行加速（可选，需 pytest-xdist）
.venv/bin/python -m pytest tests -n auto -m "not external"
```

## 5. 执行产物（reports/）

| 文件 | 用途 |
|------|------|
| `reports/pytest-report.html` | 自包含 HTML 测试报告（可直接浏览器打开 / 邮件发送） |
| `reports/junit.xml` | JUnit XML，供 CI（GitHub Actions / GitLab CI）解析 |
| `reports/coverage-html/index.html` | 行 / 分支覆盖率明细（点击进入逐文件） |
| `reports/coverage.xml` | Cobertura 格式，供 SonarQube 等 |
| `reports/summary.txt` | 纯文本摘要，验收报告可直接引用 |
| `reports/pytest-output.log` | 完整日志（含 xfail 原因 DEF-*） |

## 6. 隔离与环境变量（重要）

`tests/conftest.py` 在 import `app` 前注入，确保测试不污染开发库：

```bash
DATABASE_URL=sqlite:///./.pytest_tmp/gold_test.db   # 隔离测试库
DEMO_MODE=true
SCHEDULER_ENABLED=false
NEWS_SCRAPE_ENABLED=false
```

CI 建议：将 `reports/` 设为构建产物留存；覆盖率门禁可读取 `reports/coverage.xml` 的 TOTAL 行。

---

## 7. 常见排错

| 现象 | 原因 | 处理 |
|------|------|------|
| `unrecognized arguments: --timeout=120` | 未装 `pytest-timeout` | 重跑脚本（会自动装）；或手动 `pip install pytest-timeout` |
| `ModuleNotFoundError: app` | 不在项目根目录执行 | `cd` 到 `forecasts for gold prices/` 再跑 |
| 路径含空格报错 | 旧脚本未引号包裹 | 已修复 `run_tests.sh`（`"${PY}"` 已加引号），请更新到最新版 |
| 想跑真实爬虫 | 标记为 `external` | 用 `bash scripts/run_tests.sh full`（需外网 / Node） |

## 8. 接入 CI（示例片段）

```yaml
# .github/workflows/test.yml（示意）
test:
  runs-on: ubuntu-latest
  steps:
    - uses: actions/checkout@v4
    - uses: actions/setup-python@v5
      with: { python-version: "3.13" }
    - run: bash scripts/run_tests.sh
    - uses: actions/upload-artifact@v4
      with:
        name: test-reports
        path: reports/
```
