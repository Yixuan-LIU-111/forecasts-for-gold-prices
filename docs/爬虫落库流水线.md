# 页面爬虫 → 数据落库 流水线

打通「页面抓取 → 清洗 → 落库 → 测试验证」的完整链路，新增于 `app/pipeline/`。

## 1. 模块结构（职责分离）

| 文件 | 职责 |
|------|------|
| `app/pipeline/models.py` | ORM 表 `scraped_gold_prices`（数据层，与项目 `Base` 同源） |
| `app/pipeline/scraper.py` | 页面抓取 `fetch()` + HTML 表格解析 `parse()` + 清洗 `normalize()`（采集层） |
| `app/pipeline/store.py` | 校验 + 方言自适应 upsert 落库（服务层） |
| `app/pipeline/run.py` | 端到端编排入口（`python -m app.pipeline.run`） |
| `tests/test_pipeline.py` | 落库结果自动化测试（一致性 / 完整性 / 字段正确性） |

## 2. 数据模型 `scraped_gold_prices`

| 字段 | 类型 | 说明 |
|------|------|------|
| id | Integer PK | 自增主键 |
| source | String(120) | 数据来源标识 |
| symbol | String(20) | 标的，默认 `XAU/USD` |
| quote_date | Date | 行情日期（必填） |
| open/high/low | Float | 开/高/低（可空） |
| close | Float | 收盘（必填） |
| volume | Float | 成交量（可空） |
| currency | String(10) | 货币，默认 `USD` |
| scraped_at | DateTime | 抓取时间（UTC） |

唯一约束 `(source, symbol, quote_date)` 作为 SQLite / PostgreSQL 通用 upsert 的冲突目标。

## 3. 抓取与清洗

- `fetch(url=None, use_fixture=False)`：通过 `requests` 抓取目标页面；未配置 URL 或请求失败时回退内置样本 HTML（离线可跑）。
- `parse(html)`：BeautifulSoup 解析 `<table>`，按表头别名（中英文）自适应识别 `date/open/high/low/close/volume/currency`。
- `normalize(raw)`：日期/数值解析、价格区间校验、OHLC 一致性校验；非法行（如 `close=N/A`、`high<low`）返回 `None` 被丢弃。

## 4. 运行方式

```bash
# 使用内置样本数据（离线，无需网络）
PYTHONPATH=. python -m app.pipeline.run

# 抓取真实页面
PYTHONPATH=. python -m app.pipeline.run --url https://<your-gold-price-page>
```

## 5. 自动化测试

```bash
# 仓库根目录执行
PYTHONPATH=. python -m unittest tests.test_pipeline -v
```

覆盖维度：
- **字段正确性**：类型、价格区间 `[1, 100000]`、OHLC 一致性 `high>=max(open,close)` 且 `low<=min(open,close)`。
- **完整性**：`close` 非空、必填列非空、成交量非负。
- **一致性**：写入后往返一致；upsert 幂等（重复写入不新增行）；来源过滤正确。
- **清洗**：样本 5 行中 2 行非法被丢弃，剩 3 行有效。

## 6. 切换 MySQL / PostgreSQL

代码完全基于 SQLAlchemy 2.0 ORM，无需改动即可切换数据库：

1. 安装对应驱动：`pip install psycopg2-binary`（PostgreSQL）或 `pip install pymysql`（MySQL）。
2. 修改 `app/config.py` 的 `DATABASE_URL`：
   - PostgreSQL：`postgresql://<user>:<pass>@<host>:5432/<db>`
   - MySQL：`mysql+pymysql://<user>:<pass>@<host>:3306/<db>`
3. 落库复用 `app.core.data_collector._dialect_insert`，按 `DATABASE_URL` 方言自动选择 `pg_insert` / `sqlite_insert`，upsert 语义一致。

> 当前项目默认 SQLite（文件库 `./data/gold_predictor.db`，零依赖）。本流水线已用真实 SQLite 文件库 + 13 项测试验证通过。
