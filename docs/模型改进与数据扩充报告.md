## 1. 本次新增 / 修复内容

### 1.1 数据层扩充（`gold_prediction_model/thirty_min/data_layer.py`）
- **真实锚定 30m** `load_daily_gold_anchored()`：用 2,589 个真实日频 COMEX 收盘（2016→2026）将每日拆成 48 根 30m bar；价格轨迹端点 100% 真实（前一日收盘→当日真实收盘），日内为 realism 模拟。沙箱无外网时作为可训练的「真实价格历史」替代。
- **真实新闻压力代理** `load_macro_news_sent_zscore`：读取宏观样本 Excel 中**真实 10 年日频 GPR（地缘政治风险）/ EPU（美国经济政策不确定性）**，z-score 后过 tanh 映射到 [−1,1]，作为「过去重要新闻经量化处理」的权威代理。
- **真实新闻情感** `load_news_events()`：同时读取 6 个 LLM 量化文件 + SQLite `news` 表（22 条带 sentiment_score 的真实爬取新闻），合并为事件级情感。
- 三路真实来源经 `align_and_merge()` 以 30m 主轴对齐（前视安全 ffill + 新闻归入「≤事件时刻」最新 bar）。

### 1.2 模型改进（`automl.py` 新增 + `model.py` / `run_pipeline.py` 改造）
- **Purged Walk-Forward CV** `purged_walk_forward_cv()`：沿时间轴扩张窗口切折，折间施加 López de Prado **purging**，给出**无偏的多折泛化估计**（取代单次 70/15/15 切分的乐观估计）。
- **分阶段 AutoML 调参** `automl_tune()`：以验证折集成 AUC 为目标，分阶段搜索 `lr×n_estimators → num_leaves/max_depth → subsample/colsample → reg`，共 13 次评估。
- `model.Predictor.fit` / `fit_dual_models` 支持传入调出参数；`run_pipeline` 先跑 WF、再调参、然后「默认参数 vs 调参后」同测试集对照、再做情感消融，全程落盘 JSON 报告。

### 1.3 修复的三个关键 Bug（否则结果完全不可信）
1. **GPR/EPU 代理全空**：`out[col] = np.tanh(gz/2.0)` 触发 pandas **索引对齐**——`out` 以日期为索引而 `gz` 是位置型 Series，对齐失败 → 全部变 NaN → 被 `dropna(how='all')` 清空。改为 `.to_numpy()` 按位置赋值。
2. **真实锚定 close 全 NaN（致命）**：`pd.DataFrame({...}, index=df["ts"])` 把（RangeIndex 的）列对齐到日期索引 → 无交集 → **全部变 NaN** → 目标 `close.shift(-1)>close` 恒为 False → 标签全 0、AUC 计算直接 NaN。改为「先建表、后赋值 `out.index = df["ts"]`」。`load_price_bars` 同款 bug 一并修复。
3. **日志静默**：`get_logger` 只在首个 logger 上装 handler 且 `propagate=False`，导致 `run/automl/eval` 日志全被吞掉。改为在父 logger `thirty_min` 上统一装 handler、子 logger 复用。

## 4. 真伪辨析：0.92 的 AUC 是「构造假象」

**为什么这个高 AUC 不可信为真实 alpha？**

真实锚定 30m 的日内路径构造为：`close = linspace(前收, 今收, 48) + cumsum(噪声)×0.12`，且末根被**重新锚定**到当日真实收盘。这导致：

- 每日 48 根 bar 的端点被「钉死」，日内路径只能在真实区间内小幅游走 → **局部强均值回复**（涨了容易跌、跌了容易涨）。
- 目标 `close.shift(-1) > close`（下一根是否上涨）因此被技术特征（`ret_1`、`ma_dev`、`rsi`、`vol_z`）高度预测 —— 这是**数学构造的必然**，不是黄金市场规律。
- 真实黄金 30m tick 近似随机游走，**不存在**这种端点钉死带来的可预测性，其方向 AUC 通常贴近 0.5。

**证据**：消融显示情感特征增量≈0（§5），且 `profit_drawdown` 的「累计收益 32 万倍」明显是 demo 回测把每根正确方向 bar 都按 +0.1% 复利造成的数值假象，**绝非真实收益**。

> **结论**：当前指标只能证明「流水线在真实价格水平上能端到端跑通并稳定拟合」，**不能**证明模型具备真实预测力。要得到可信评估，必须用**真实 tick 级 30m K 线**替换锚定模拟路径后重跑。

---

## 5. 情感特征增量≈0 的根因（覆盖，非特征无效）

消融 ΔAUC = −0.0001，结论「情感增量有限」。但这是**数据覆盖问题**，不是「情感没用」：

1. **事件密度极低**：120 条新闻散落在 124,272 根 bar 上 → **99.9% 的 bar 没有任何新闻**，`sent_*` 全为 0、`has_news=0`。
2. **时间对齐粗糙**：多数新闻只有日期无时刻，被保守放到当日 23:30，无法落到具体 30m bar，导致情感窗口聚合几乎恒为 0。
3. **GPR/EPU 代理太慢**：日频 → ffill 到 30m 后日内基本恒定，无法驱动 30 分钟级别的方向变化；而目标（合成日内噪声）本就不受宏观慢变量影响。

**所以**：情感「喂满」的工程通道已建好（LLM 情感 + 鹰鸽 + GPR/EPU 代理全部接入），瓶颈在**真实事件/真实 tick 的覆盖度**，而非特征设计。
